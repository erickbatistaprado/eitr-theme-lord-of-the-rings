# Lord of the Rings theme for Eitr

A dark [Eitr](https://eitr.info) theme with Lord of the Rings fan art: One Ring gold on
Middle-earth night, with six wallpapers.

![Preview](lord-of-the-rings/preview.png)

## Install

Open the Eitr Store, choose Themes, and search for Lord of the Rings.
